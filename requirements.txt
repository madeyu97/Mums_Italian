# FULL LOCKFILE — direct *and* transitive dependencies are pinned.
#
# WHY EVERYTHING IS PINNED, NOT JUST THE OBVIOUS PACKAGES:
# Pinning only the six packages this app imports directly was NOT enough.
# On 2026-08-05 a redeploy pulled starlette 1.4.0 (a transitive dependency
# of streamlit, which declares a very wide range: starlette<2,>=0.46.0).
# starlette 1.4.0 added a REQUIRED keyword-only argument to
# GZipResponder.__init__(), which streamlit 1.61.0 does not pass. Every
# HTTP request then died with:
#     TypeError: GZipResponder.__init__() missing 1 required
#     keyword-only argument: 'thread_minimum_size'
# The server returned 500 to health checks and the app never loaded —
# with zero changes to this repo's code.
#
# These exact versions are the set that was verified working together on
# Streamlit Cloud (Python 3.14.6). Locking all of them makes every reboot
# reproducible instead of a fresh dependency-resolution lottery.
#
# TO UPGRADE (deliberately, never by accident):
#   1. Change ONE pin.
#   2. Commit, let it deploy, run a short study session.
#   3. If anything breaks, revert that one line.
# Note: bumping `streamlit` may require bumping `starlette` with it.
